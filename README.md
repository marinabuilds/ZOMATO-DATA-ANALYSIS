# ZOMATO-DATA-ANALYSIS
Overview
This project focuses on analyzing the Zomato Dataset using Python and Data Analysis techniques.
The objective of this project is to preprocess, clean, and analyze restaurant data from Zomato to discover meaningful insights about restaurants, ratings, pricing, and customer preferences and many more..
The project demonstrates the complete data analysis process including:
Data Collection,Data Cleaning,Data Preprocessing,Data Visualization
Technologies Used are
Python,Pandas,NumPy,Matplotlib,Seaborn,Jupyter Notebook
